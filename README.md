# Fieldwork Festival

Concept event page for the Arrived Design Partner application (Happily), October 2026. Fieldwork Festival is a fictional event. The pass form is a demo: nothing is sent or saved.

- Plain HTML, CSS and vanilla JS. No framework, no build step.
- Content is written straight into `index.html`, so the page reads fine even before JavaScript loads.
- Fonts are self-hosted in `fonts/` (Bricolage Grotesque and Instrument Sans, SIL Open Font License).
- Speaker photos in `img/speakers/` are stock placeholders from Unsplash (Unsplash License), shown with a riso-style SVG filter.
- Color roles: forest = Main Stage, lilac = Studio, butter = Maker Market.

## Run locally

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

## Deploy

GitHub Pages: Settings > Pages > Deploy from a branch > `main` / `(root)`.
